# Check Yer B*tthole, THE GAME

An idle clicker about checking yer butthole. Play it at https://thegrumpygamedev.itch.io/check-yer-btthole

Originally vanilla JavaScript (June 2025, preserved in `reference/original/`). Being ported to Odin compiled to `js_wasm32`. See [PLAN.md](PLAN.md) and [docs/original-rules.md](docs/original-rules.md).

## Build

```bash
odin/build.sh    # writes odin/out/; serve it with any static server
```
