Check Yer B*tthole is now in Odin

Yer butthole got an update, and it looks exactly the same.

I rebuilt the whole game in Odin and compiled it to WebAssembly. It is the same buttons and the same plain page as before, and if you had a game going, it carries over. Press Continue and yer progress is still there.

I wrote this with Claude Code, which did most of the typing.

What's different:

- Critical Check % is now something you buy. The old version rolled its dice wrong, so even at 0% you would crit about one time in a hundred. With no upgrades you now get no crits, and each level is worth exactly what it says.
- Buying an advancement saves right away. Before, it only saved when you went back to the main screen, so closing the tab at the wrong moment lost yer purchase.
- An advancement at max level says MAX instead of "Cost: undefined".
- If yer browser blocks saving, the game still runs for that visit instead of falling over.

What's the same: everything else. The numbers, the costs, the wording and the look.

Thanks for checking.
