# Playtest, 2026-10-06 (phase 7)

Real browser (the Claude desktop app's browser pane), build from `odin/build.sh`, served from `odin/out` on localhost. The original game (`reference/original/`) was served beside it to produce a genuine old save and to compare.

## Passed

- **Migration from a real old save.** Played the original through its own UI (embark, 30 checks, 3 upgrades bought, one more check) and carried its `worldData` to the port's origin. Continue showed the same name, XP, irritation, points, check count and the same "Next irritation recovery" time as the original. The old key stayed byte for byte (379 characters) and `cyb:save` was written on Continue.
- **v2 wins over the old key** (old key edited to a different name; the v2 name showed).
- **Corrupt `cyb:save`** (`xp_goal` 0) and a **60,000 character value**: Start screen, no console errors, the values left in place.
- **Recovery over real time:** a v2 save with the last check 10 minutes ago, irritation 31, recovery level 2 (50 s): "-12 Irritation", then the check (31 - 12 + 1 = 20).
- **Level up:** XP 99 plus a 2 XP check gave level 1, XP 1/200, +1 point (10).
- **Irritation cap:** 20 to 100 over 80 checks; the 81st showed "Yer butthole is too irritated!" and gave no XP.
- **Buying:** Crit level 2 to 3 for 4 points (10 to 6), saved at once; Thoroughness showed no Buy! at 6 of 10 points.
- **Abandon:** No returns to the menu with the save intact; Yes returns to Start.
- **A new game over the abandon marker**, 5 checks, reload, Continue: restored.
- **DOM structure** matches the original element for element (neutral: 9 paragraphs then 3 buttons; list: heading, buttons separated by `<br>`; and so on). The two pages look identical at desktop size.
- **Phone width (375 px):** no horizontal scroll.
- **Storage blocked** (a copy whose `localStorage` throws): the game starts and is playable for the session, no errors. (The original throws.)
- **HTML in a name** (`<b>Test</b>`) shows as literal text.

## Found and fixed

- **Abandoned games came back.** Abandon removed `cyb:save`; on the next load there was no v2 save but the old `worldData` was still there, so it was migrated back in (Continue appeared instead of Start). Fix: abandon now stores `{"version":2,"empty":true}` in `cyb:save`, and `load_game` treats that as "new format in charge, no game". Regression tests: `the_empty_marker_stops_the_old_save_coming_back`, `a_new_game_replaces_the_marker`.

- Two tabs open at once: the last save wins, as in the original.
